# BUILD SPEC v3 — Same-equipment supersets

Supersedes the session/station structure in `SPEC.md` and `SPEC_V2.md`. Everything else still applies.

## 1. The change the client asked for
> "Moving between equipment for a superset is not feasible in a busy gym. Update to keep supersets on
> same equipment."

**Rule: each superset pair must be performed on ONE piece of equipment, in one spot.** No walking between
machines, racks or benches inside a pair. Moving between *stations* is fine — that happens during rest.

Every session is still **≤ 45 minutes** and the modelled worst case is **41.0 min**.
