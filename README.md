# Upper Body 12-Week

A 12-week **upper-body-only** program that alternates one **strength day** with one **cardio day**,
every day of the week — **7 training days per week, zero rest days**. Legs are deliberately excluded.

**Live site:** https://colinlcoateshermes.github.io/Upper-Body-12-Week/

## What's inside

- **Weekly pattern** (repeats all 12 weeks): Mon STRENGTH A (Push) · Tue CARDIO 1 (easy Zone 2) ·
  Wed STRENGTH B (Pull) · Thu CARDIO 2 (intervals) · Fri STRENGTH C (Shoulders & Arms) ·
  Sat CARDIO 3 (bodyweight circuit) · Sun STRENGTH D (Hypertrophy + Core).
- **Totals:** 12 weeks = 84 days = 48 strength sessions + 36 cardio sessions, 0 rest days.
- **5 periodisation blocks:** Foundation → Volume → Strength → Peak Overload → Deload & Retest.
- **68 animated exercise GIFs** sourced from [ExRx.net](https://exrx.net), each linked to its
  reference page, plus a full exercise library grouped by muscle group.
- **Interactive:** an 84-day tick-off tracker with `localStorage` persistence and save/restore,
  collapsible strength cards, and a block selector that updates every prescription.

## Files

- `index.html` — the single self-contained page (inline CSS + vanilla JS, no frameworks, no CDN).
- `images/` — 68 animated technique GIFs from ExRx.net.
- `build_site.py` / `download_gifs.py` — the build scripts that generated the page and assets.
